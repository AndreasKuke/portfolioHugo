## A bit of a ramble

Coding agents are becoming more of a daily thing in developers life, and i'm not one to shy away of the idea of it being able to help.

Where i think coding agents especially shine is when a developer knows how to code and knows how to prompt it properly for correct output or error handling.

If a system can take up to 5 hours to debug for a single dev, but you can cut that in half to 2.5 hours with the help of an agent, and it doesnt have any consequences for the outcome of the product. Then i don't see why it shouldn't be a thing.

Again i heavily emphasize that i still think the so-called developer, needs to know how to code before they start using it.
